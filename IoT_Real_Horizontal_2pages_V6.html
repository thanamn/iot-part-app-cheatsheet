Spatial Filtering vs Convolution

  • Filtering (correlation) = ไถ kernel หาผลรวมผลคูณ ตรง ๆ
  • Convolution = พลิก kernel 180° ก่อน → output คล้าย kernel · สมมาตร = เท่ากัน · ใช้ cv2.filter2D
  • Box/Average (cv2.blur) = เบลอ · kernel ใหญ่ขึ้น = เบลอแรงขึ้น + ช้าลง (ไม่ใช่คมขึ้น/fps ขึ้น)
  • Gaussian = เบลอนุ่ม ถ่วงกลาง · Laplacian = เหลือแต่ขอบ (อนุพันธ์อันดับ 2) ขยาย noise
  • Sobel/Prewitt = ขอบตามแกน x/y · Sharpen = คมขึ้น

Lab 1 · Face Detection + Blur

ไปป์ไลน์: Frame capture (OpenCV) → Haar Cascade → Privacy Blur → Logging → Flask MJPEG Stream

  • สายกล้อง Pi = MIPI CSI-2 serial (ไม่ใช่ USB/UVC, I²C, SPI, HDMI)
  • create_preview_configuration(main={"format":"XRGB8888","size":(640,480)}) → XRGB8888 = 4 ไบต์/พิกเซล (R,G,B+X; หน่วยความจำเรียง B,G,R) · capture_array()
  • สตรีมขึ้นเว็บ = Flask + HTTP (MJPEG) ไม่ใช่ MQTT/WebSocket/gRPC
  • Haar เร็วเพราะ Integral Image (sum เร็ว) + Cascade Stages (ตัดพื้นหลังไว) · Sliding Window ไถทั่วภาพ
  • scaleFactor ↑ เร็วแต่พลาดขนาด · minNeighbors ↑ FP น้อย · minSize ↑ เร็ว
  • fps ต่ำแก้ที่: โหลด Cascade ครั้งเดียวนอกลูป (ต้นเหตุหลัก) · ย่อภาพ · ตรวจทุก N เฟรม + cache กรอบ · frame pacing แก้ jitter
  • log ISO 8601 ต้อง timespec="seconds" (ไม่ใส่ = มีไมโครวินาที) · open("log.txt","a")
  • status: ABSENT=0 · NORMAL=1 · SUSPICIOUS≥2 · เขียน log ทุก 1 วิ / เมื่อ status เปลี่ยน (ไม่ทุกเฟรม)
  • เช็ค OS cat /etc/os-release · Bullseye libcamera-* → Bookworm rpicam-*
f = cv2.CascadeClassifier(cv2.data.haarcascades
    + 'haarcascade_frontalface_default.xml')  # load once
faces = f.detectMultiScale(gray, scaleFactor=1.1,
  minNeighbors=5, minSize=(30,30))
for (x,y,w,h) in faces:
  frame[y:y+h,x:x+w] = cv2.blur(frame[y:y+h,x:x+w],(25,25))

fps = 1 / เวลาต่อเฟรม (s) → 50 ms = 20 fps · ในแล็บช่วงหน้าเริ่มเบลอ = 11–25 fps
