## Printing

Open the HTML in a browser → Print → **A4**, **Landscape**, margins **None**, background
graphics **on**. Output is exactly 2 pages (one double-sided sheet).

Fonts (IBM Plex Sans Thai / Condensed / Mono) load from Google Fonts, so open/print while
online, or just use the pre-rendered PDF.
