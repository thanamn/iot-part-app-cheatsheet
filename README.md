# IoT Part App — Cheat Sheet (2110575)

A dense, print-ready cheat sheet for **2110575 · IoT Part App** (Weeks 1–3, Quiz).

Layout: **one A4 sheet, double-sided — 2 landscape pages**, three columns each.

- **Page 1** — theory/concept (Lectures 1–3): IoT basics & 9 characteristics, 4 layers,
  Smart City use cases, communication models, storage & databases, processing models,
  Edge/Fog/Cloud, IoT levels, user-facing apps, protocols, commonly-swapped pairs,
  "which is NOT" checklists, lab commands & libraries, glossary, troubleshooting.
- **Page 2** — evaluation & labs 1–3: 7 IoT + 6 AI-specific evaluation criteria,
  Haar face detection, filtering vs convolution, OCR (EasyOCR, parameters, metrics),
  MediaPipe hands, common traps, key numbers, scenario → answer, worked calculations,
  `code # what it does` reference.

## Printing

Open a file from `html/` in a browser → Print → **A4**, **Landscape**, margins **None**,
background graphics **on**. Output is exactly 2 pages (one double-sided sheet).

Fonts (IBM Plex Sans Thai / Condensed / Mono) load from Google Fonts, so open/print while
online — or just use the pre-rendered PDF in `pdf/`.
